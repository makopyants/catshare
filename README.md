# 🐾 catshare — лендинг про котят

Страница живёт на GitHub Pages: **https://makopyants.github.io/catshare/**

## Как добавить фото и видео

Просто положи файлы в папку `media/` и запушь:

```bash
cp ~/Desktop/kitten1.jpg media/
git add media/
git commit -m "add photos"
git push
```

Через минуту-две они сами появятся на странице — галерея читает содержимое
папки `media/` автоматически, ничего в коде менять не нужно.

Поддерживаемые форматы:
- **Фото:** jpg, jpeg, png, webp, gif, avif
- **Видео:** mp4, webm, m4v (mov может не открыться в Chrome на Windows/Android — лучше конвертировать в mp4)

Файлы показываются по алфавиту (фото сначала, видео после). Хочешь задать
порядок — назови их `01-...jpg`, `02-...jpg` и т.д.

Ограничение GitHub: один файл — до 100 МБ. Длинные видео лучше сжать.

## Как поменять текст и контакты

Всё в `index.html`:

- **Заголовок и описание** — ищи комментарии `ЗАГОЛОВОК` и `ОПИСАНИЕ` в начале `<body>`.
- **Контакты** — блок `CONTACTS` в начале `<script>`: впиши ник в Telegram,
  телефон и номер для WhatsApp. Пустая строка — кнопка не показывается.

После правок — `git add`, `git commit`, `git push`, как с фотографиями.

## QR-код

Готовые QR-коды со ссылкой на страницу лежат в папке `qr/`:
`qr-code.png` (для печати) и `qr-code.svg` (масштабируется без потерь).
